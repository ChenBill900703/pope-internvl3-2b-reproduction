# 公開資料與保存政策

公開內容採明確允許清單：本研究原創程式、環境版本、整理報告、自動生成的彙整JSON/CSV及PNG/SVG、必要來源雜湊。未確認再散布權利的內容一律不納入Git。

不公開：`.venv`、模型權重、圖片、完整COCO/GQA/A-OKVQA資料、原論文PDF／全文擷取、第三方clone、原始逐題問題與參考答案、原始模型回答SQLite/JSONL、完整含逐題資料的審查ZIP、帳密與個人聯絡資料、快取、暫存、私人本機路徑、歷史執行日誌。公開聚合表不含影像或逐題題號。

所有原始結果仍保留本機原路徑。既有 `FINAL_REPORT_zh-TW.md`、`REPORT_zh-TW.md` 與 `STATUS.md` 不改寫，也不隨公開庫散布其未清理的本機路徑或逐題內容。新版教授入口是根目錄README與PAPER_SUMMARY。

本機公開前保護清單記錄舊檔SHA，另備份原README與可編輯文件／程式。正式結果、先前VQA A/B/C與D資料必須逐檔維持相同SHA；SQLite共用記憶體暫態 `-shm` 與Python快取不列內容證據，SQLite主檔與WAL都列入核對。

公開的來源hash只用相對路徑，可供持有合法資料的人交叉核對；不代表資料已公開，也不構成第三方再散布授權。提供教授完整逐題資料前，需依其取得方式與來源使用條件另行處理；本次不將私有審查ZIP上傳公開網站。
